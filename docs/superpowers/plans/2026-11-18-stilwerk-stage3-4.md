# Stilwerk Stage 3+4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Detail assistant (8 rule-based suggestion types with 3 variants, checklist + targeted UI) and interior designer (room detection, data-driven furniture modules with vanilla + Macaw's/Refurbished variants, recipe-based generator).

**Architecture:** Both features are pure planners over a `BlockGetter` that output `ChangeSet`s, reusing Stage 1+2 (Applier, MaterialLedger, UndoHistory, GhostMesh, ServerOps pattern). Client previews, server recomputes from (selection/click, seed, choice).

**Tech Stack:** as Stage 1+2. Modules/recipes generated by `tools/make_interior.py` into `data/stilwerk/stilwerk_interior/*.json` (classpath, identical on both sides).

**Spec:** `docs/superpowers/specs/2026-11-18-stilwerk-stage3-4-design.md` · conventions as in the Stage 1+2 plan (`bash tools/gt.sh`, Write tool for Java, lang via `tools/make_lang.py`).

## Binding interfaces

```java
// detail
public final class BuildingView {             // over a resolved selection
    public BuildingView(BlockGetter level, ResolvedSelection sel);
    public boolean built(BlockPos p);         // in selection, not air, not natural
    public boolean outside(BlockPos p);       // air/replaceable reachable from the bounds (inflated 2) border
    public boolean free(BlockPos p);          // air or replaceable and not protected
    public Family wood();  public Family stone();   // dominant families (fallback oak / stone_bricks)
    public BlockGetter level(); public ResolvedSelection selection(); public BoundingBox bounds();
}
public record Suggestion(String rule, BlockPos anchor, BoundingBox area, List<Variant> variants) {}
public record Variant(String key, ChangeSet changes) {}            // key = translation key
public record Choice(String rule, BlockPos anchor, int variant) {}  // + StreamCodec
public interface DetailRule { String id(); void find(BuildingView v, DetailContext ctx, List<Suggestion> out); }
public final class DetailContext { long seed(); Materials mats(); Edit edit(); }   // Edit = ChangeSet builder: put (free only) / replace (built only)
public final class DetailPlanner {
    public static List<DetailRule> rules();
    public static List<Suggestion> find(BlockGetter level, ResolvedSelection sel, long seed);
    public static List<Suggestion> near(BlockGetter level, BlockPos clicked, long seed); // 17³ analysis, anchor/area within 3 of click
    public static ChangeSet combine(List<Suggestion> all, List<Choice> choices);       // first change per position wins
}
// interior
public record Room(BlockPos start, LongSet air, LongSet floor, int floorY, BoundingBox bounds,
                   Map<Long, Set<Direction>> walls, List<BlockPos> doors, LongSet doorClear, List<BlockPos> windows, LongSet windowFloor) {}
public final class RoomDetector { public record Result(@Nullable Room room, @Nullable String error, @Nullable BlockPos at) {}
    public static Result detect(BlockGetter level, BlockPos clicked, Direction face); }
public record Module(String id, String category, Vec3i size, String placement, List<String> requires, Blueprint blueprint) {}
public final class ModuleLibrary { public static List<Module> available(String category); public static List<RoomType> types(); }
public record RoomType(String id, List<Slot> slots, boolean rug, boolean light) { public record Slot(String category, int min, int max, int priority, String prefer) {} }
public final class WoodAdapter { public static BlockState adapt(BlockState s, Family wood, DyeColor color); }
public final class InteriorGenerator {
    public record Result(ChangeSet changes, List<String> placedModules) {}
    public static Result generate(BlockGetter level, Room room, RoomType type, long seed, Family wood);
    public static RoomType auto(BlockGetter level, Room room);
}
// net
DetailRequest(int id, Selection selection /* or null */, BlockPos clicked /* targeted mode */, long seed, List<Choice> choices, boolean partialOk)
InteriorRequest(int id, BlockPos clicked, Direction face, String type, long seed, boolean partialOk)
```

## Tasks

### Task A: Wand modes DETAILS + INTERIOR, wheel with 5 tiles
- [ ] `WandMode` adds `DETAILS(Items.FLOWER_POT)`, `INTERIOR(Items.RED_BED)`; ModeWheelScreen angles for 5 tiles (−90, −18, 54, 126, 198); lang keys. Compile, GameTests green, commit.

### Task B: BuildingView, Materials, Edit, DetailContext + tests
- [ ] Outside flood over the selection bounds inflated by 2 (6-neighbours through free cells, seeded from all border cells). Dominant families from a census of built blocks (wood: `family.wood()`; stone: has FULL+STAIRS, not wood).
- [ ] Tests: hut → wall cell outside face true, interior air false, wood() = oak family for an oak hut, stone() = stone_bricks for brick base.

### Task C: Rules (each own class in `detail/rule/`, each with GameTests)
- [ ] `StairsRule`: runs ≥2 of bottom stairs ascending in `facing`, run width ≤3, two air cells above each step; sides with free cells → variants fence / wall / open trapdoor (facing = side) + lantern on the lowest post (fence/wall variants).
- [ ] `EavesRule`: bottom stairs whose low side (−facing) and below are outside → grouped per edge line; variants upside-down stair below (facing = stair facing) / open trapdoor in front (facing = −(−facing)) / bottom slab in front.
- [ ] `WindowRule`: glass/pane clusters in the wall plane with outside in front (D); variants shutters (open trapdoors left/right of each row, facing D) / stair frame (top: half=top facing −D above; bottom: bottom stair below) / flower box (persistent flowering azalea leaves below + open trapdoor in front facing D).
- [ ] `PillarsRule`: outer wall segments (built FULL blocks with outside in front, ≥3 high) of length ≥5 → columns at both ends + every 4th: replace FULL members with LOG(axis y) / STRIPPED_LOG / stone FULL.
- [ ] `PlinthRule`: lowest outer wall row → replace with stone FULL (wood walls) or cobblestone (stone walls) / stair skirt in front (facing −D) / mossy mix (seeded pick of mossy_stone_bricks, stone_bricks, cracked_stone_bricks).
- [ ] `CornerRule`: convex outer corners (outside in two perpendicular directions), y = top of column − 1 → fence at diagonal cell + hanging lantern below / chain + hanging soul lantern / wall torches on both faces.
- [ ] `EntranceRule`: lower door halves with outside in front → fence posts with lanterns left/right / top-slab awning 3 wide above / stairs down in front while air below (≤3), only if elevated.
- [ ] `PlainRule`: in-plane connected components ≥12 of one FULL block on outer faces → up to 3 mixes (by family: stone/cobble → old_mossy, castle_wall, framed_stone; wood → weathered_wood; deepslate → rough_deepslate; sandstone → sandstone_worn; nether bricks → nether_rough).
- Tests per rule: a minimal build that triggers it → ≥1 suggestion with 3 (or 1–3 for plain/entrance) non-empty variants; variant changes only touch free cells (put) or built FULL cells (replace); wood material follows the building (spruce build → spruce fence/trapdoor).

### Task G: Modules, ModuleLibrary, WoodAdapter, make_interior.py + tests
- [ ] `tools/make_interior.py` writes `modules.json` and `recipes.json` (vanilla modules for every category; Macaw's (`mcwfurnitures`) and Refurbished (`refurbished_furniture`) variants with `requires`). Block strings use tokens `COLOR` (room colour) and oak wood names.
- [ ] Loader parses with `BlockStateParser` against `BuiltInRegistries.BLOCK`; modules whose `requires` are not loaded or with unknown blocks are skipped (logged once).
- [ ] WoodAdapter: vanilla wood family members via family/shape mapping; modded ids by replacing the `oak` token (not `dark_oak`) with the target wood path when that block exists; `COLOR` → dye colour (fallback white).
- [ ] Tests: every category has ≥1 available module without mods; adapt oak_stairs → spruce_stairs keeps facing; `COLOR_bed` → `red_bed`.

### Task H: InteriorGenerator + recipes + tests
- [ ] Candidates per slot: floor cell × 4 rotations × modules of the category; fit (footprint cells all floor & free, height ≤ room height at those cells, wall placement needs every back cell to have the wall behind in the rotated north direction; corner additionally a side wall; window = wall placement on windowFloor); never in doorClear; score by `prefer` + `Hash.unit` jitter; after placing, BFS from every doorClear cell over free floor must still reach all remaining free floor cells (else reject).
- [ ] Rug: largest free rectangle (≥2×2) of floor cells not adjacent to doorClear → `COLOR_carpet`. Ceiling light: height ≥3 at the room centre → chain(s) + hanging lantern from the ceiling down to y+2.
- [ ] Module cells: rotate via `Transform`, adapt via WoodAdapter, all marked `reshape=true` (furniture connections recomputed by the Applier's reshape pass).
- [ ] `auto`: furnace/anvil/blast furnace in room → workshop; bed → bedroom; ≥3 containers → storage; floor ≤12 → bath? no: floor ≤ 12 → bedroom; else living.
- [ ] Tests: bedroom in a 7×3×6 room → a bed placed, door clearance empty, all free floor reachable, deterministic per seed, changes only into free cells; every type generates ≥1 module in a 9×4×9 room without mods.
